# PC-16 Knowledge Lake Product — Customer-visible Changes

**Package:** PC-16  
**Date:** 2026-08-16

## Can now

- Open **Knowledge Lake** from Research (nav after Research, Overview tile)
- Browse existing analytical facts with search and filters (source, type, strategy, report, date)
- Open any entry, inspect metadata, payload, provenance, and references
- Navigate relationships
- Browse ingestion history
- View connected Reports, AI narrative references, Research, Strategies, and market refs when already present
- Export the existing projection as JSON

## Still cannot

- Edit, delete, or manually ingest Lake facts
- Treat Lake facts as ledger Source of Truth
- Use `/knowledge` as the warehouse (that page remains Research Knowledge)
- Author AI narratives (PC-17)
- Generate reports from the Lake UI
- Use a new export format

## Copy the operator sees

Knowledge Lake stores analytical copies. If they conflict with Ledger, Fills, Orders, or Session, Source of Truth wins. Live on a fact is a labeled projection, not live trading.

**End of Customer-visible Changes.**
