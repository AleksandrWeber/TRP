# PC-08 Qualification Product — Customer-visible Changes

**Package:** PC-08  
**Date:** 2026-08-15

Operators can:

- Open Qualification from Research nav or the Overview tile
- See workspace targets, lifecycle, confidence, health, runs, and history
- Request qualification for a Cluster + market (paper or lab)
- Confirm a requested run before heavy work
- Cancel, record completion, or record failure
- Request requalification on a qualified target
- Open a run and inspect its summary

Operators cannot:

- Score a market or edit confidence/health calculations
- Force a trade or start a session from this product
- Treat Qualification as Profile or Market State
- Request live-capital qualification
