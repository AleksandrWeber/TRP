# PC-14 Workspace Management — Release Notes

**Package:** PC-14  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## What you can do now

- See the current workspace in the operator header.
- Open the workspace switcher.
- Create a named workspace.
- Rename a workspace.
- Archive a workspace (with confirmation).
- Switch the active workspace.
- Keep that selection after a page refresh.

Work in a workspace stays in that workspace. Switching changes the context the rest of the product uses.

---

## What this is not

- Not a tenant or organization redesign.
- Not teams, invitations, or new permissions.
- Not Live Trading.
- Not Strategy Library (next after review).

This is a paper-first research and paper-trading product. Workspace is the working context inside that product.
