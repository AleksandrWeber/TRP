# PC-17 AI Analytics Product — Customer-visible Changes

**Package:** PC-17  
**Date:** 2026-08-16

## Can now

- Open **AI Analytics** from Research (nav after Knowledge Lake, Overview tile)
- Browse existing analyses derived from ReportRuns
- Generate explain / summarize / trends / narrative from an existing report
- Compare two existing reports or cited strategies
- Inspect narrative details, recommendations, reasoning, and provenance
- Follow Knowledge Lake, Reporting, and Strategy Library references
- Browse analysis history

## Still cannot

- Treat AI text as Source of Truth or a trading decision
- Author narratives by hand
- Generate orders, edit strategies, or edit knowledge
- Send notifications from this product
- Persist a new warehouse
- Use `/ai` as RC-24 AI Analytics (that page remains the OpenRouter gateway)

Explanation, not an order. If this text conflicts with Ledger, Fills, Orders, Session, Library, or Enforcement, Source of Truth wins.
