# PC-03 Deployment Product — Release Notes

**Package:** PC-03  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## Customer-visible changes

- Open **Deployment** in the operator shell.
- Create a paper Deployment from a certified Library Version (wizard).
- See Deployment status (draft / approved).
- Approve a draft. Approval freezes configuration.
- Read Deployment history.
- Inspect metadata, Library Version, and the Runtime Validation result.
- Create is blocked when the Gate FAILs. There is no override.

This does **not** start a Trading Session and does **not** deploy live capital. Paper Bots remain a labeled sandbox.

---

## What this is not

- Not a Deployment redesign.
- Not a Deploy Engine.
- Not automatic deployment.
- Not a new Deployment authority.
- Not Runtime or Library redesign.
- Not Trading Session / Orchestrator.
- Not Live Trading.

This is a paper-first product. Deployment is the certified bind workflow before Orchestrator and paper session start.

**End of Release Notes.**
