# PC-05 Reporting Product — User Value

**Package:** PC-05  
**Date:** 2026-08-15

Operators can now work with Reporting as a product.

Before this package, ReportRuns were generated, AI narratives were attached, and deliveries were recorded, but there was no customer UI or RC-24 REST. Operators could not browse, inspect, search, or export those artifacts.

After this package, an operator in a workspace can:

- Open Reporting Home and see existing ReportRuns
- Search and filter by kind, status, and mode
- Open a run and read metadata, aggregations, narrative, and delivery status
- Open history of the same ReportRuns
- Export the existing aggregation projection as JSON
- Reach a session’s latest ReportRun from Command Center

They still cannot treat reports as ledger SoT. They cannot generate new report types. They cannot configure Notification (PC-06) or use a standalone AI Analytics product (PC-17). They cannot trade.
