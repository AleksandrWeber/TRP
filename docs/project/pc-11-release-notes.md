# PC-11 Trading Orchestrator Product — Release Notes

**Package:** PC-11  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## Customer-visible changes

- Open **Orchestrator** in the operator shell.
- Browse orchestration plans and their lifecycle.
- Request paper orchestration from a certified Library Version and an approved Deployment.
- Observe orchestration progress.
- Inspect Session Handoff Intent. It does **not** create a Session.
- Read orchestration history.

This does **not** start a Trading Session and does **not** place orders. Paper Bots remain a labeled sandbox. Certified session start is later.

---

## What this is not

- Not an Orchestrator redesign.
- Not a Session redesign.
- Not a Deployment or Runtime redesign.
- Not Session creation.
- Not Orders or Execution.
- Not Risk approvals.
- Not Live Trading.

This is a paper-first product. Orchestrator coordinates. Trading Session remains the Session owner.

---

**End of Release Notes.**
