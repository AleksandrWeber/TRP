# PC-02 Certification Product — Release Notes

**Package:** PC-02  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## Customer-visible changes

- Open **Certify** in the operator shell.
- Submit a research strategy for certification.
- Attach required backtesting and walk-forward evidence references.
- Confirm an irreversible admit into Strategy Library.
- Watch certification progress, then the result.
- Read failure reasons when a candidate is rejected.
- Read a success summary and certification metadata when admitted.
- Browse certification history.
- See certification badges on the Strategy Library version immediately after a successful admit.

**Research strategies** remains the experimental record editor. Certify admits a Library version that points at that record. It does not turn CRUD into Library.

---

## What this is not

- Not a new certification engine.
- Not Strategy Approval or manual override.
- Not a Strategy Library redesign.
- Not Runtime Validation / Gate.
- Not Deployment.
- Not Live Trading.

This is a paper-first product. Certification is the admit step into certified Library membership.
