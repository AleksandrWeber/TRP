# PC-05 Reporting Product — Customer-visible Changes

**Package:** PC-05  
**Date:** 2026-08-15

## Can now

- Open **Reporting** in the Research band
- Browse existing ReportRuns with search and filters
- Open report details, history, narrative, and delivery status
- Export the existing aggregation projection as JSON
- Follow a Command Center session’s latest ReportRun into Reporting

## Still cannot

- Treat reports as ledger Source of Truth
- Generate a new report type or PDF
- Configure Notification preferences (PC-06)
- Use a standalone AI Analytics product (PC-17)
- Trade, deploy from a report, or override delivery

## Copy the operator sees

Reports are analytical projections. If they conflict with Ledger, Fills, Orders, or Session, Source of Truth wins. Live on a report is a labeled projection, not live trading.
