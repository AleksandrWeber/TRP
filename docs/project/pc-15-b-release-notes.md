# PC-15 Slice 15-b — Release Notes

**Package:** PC-15 slice 15-b  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## Customer-visible changes

- Completing a Market Qualification now **publishes a Market Profile version** on the certified in-process path.
- That version becomes **latest**. Consumers that already read latest Profile see it immediately.
- Earlier Profile versions stay readable and unchanged.
- Qualification history stays unchanged.
- Failed or cancelled Qualification does **not** publish a Profile.

This slice adds **no new screen and no new REST**. Qualification and Profile product UI remain later packages (PC-08 / PC-09). This does **not** score markets and does **not** enable live trading.

---

## What this is not

- Not a Qualification redesign.
- Not a Profile redesign.
- Not scoring or new profile calculations.
- Not a new authority or Source of Truth.
- Not PC-08 / PC-09 product UI.
- Not PC-15 slices 15-c … 15-f.

This is a paper-first product. Qualification remains the qualification owner. Profile remains the profile-version owner.

---

**End of Release Notes.**
