# PC-13 Command Center Product — Release Notes

**Package:** PC-13  
**Date:** 2026-08-15  
**Audience:** Operators using the paper-first product  
**Live Trading:** Not implied. Not enabled.

---

## Customer-visible changes

- Open **Command Center** as the paper operations console.
- View active paper sessions and the bot list.
- Create a paper bot from an approved Deployment (existing Session workflow).
- Pause, resume, and stop paper sessions.
- Monitor session lifecycle, health, and runtime status.
- Inspect Deployment reference and Orchestration reference (`createsSession: false`).

This does **not** place orders and does **not** enable live trading. Paper Bots remain a labeled sandbox. Emergency Controls stay hidden. Certified Orchestrator → Session consume is later.

---

## What this is not

- Not a Trading Session redesign.
- Not an Orchestrator redesign.
- Not a Deployment or Runtime redesign.
- Not Orders or Execution.
- Not Risk approvals.
- Not Live Trading.
- Not a UI-only Kill Switch.

This is a paper-first product. Command Center is command UI. Trading Session remains the Session owner.

---

**End of Release Notes.**
