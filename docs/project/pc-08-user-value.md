# PC-08 Qualification Product — User Value

**Package:** PC-08  
**Date:** 2026-08-15

Operators can inspect and manage Market Qualification as a product. They can see workspace targets, existing runs, lifecycle, confidence, health, and history. They can request qualification, confirm before heavy work, cancel, record completion or failure, and request requalification on a qualified target.

This is market research for Orchestrator confidence via Profile. It does not score markets, force trades, or start sessions.
