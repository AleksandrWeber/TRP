## What you can do now

- Open **Strategy Library** in the operator shell.
- Browse certified membership for the active workspace.
- Search and filter by certification / deprecation / archive state.
- Inspect version history.
- See certification, eligibility, and envelope state.
- Open a version in read-only form (immutable; cannot be edited).

An empty library is a real product state until a version is certified.

**Research strategies** remains the experimental record editor. It is not the Library.

---

## What this is not

- Not a new Strategy Library.
- Not Certification (you cannot admit a candidate from this page).
- Not Runtime Validation / Gate.
- Not Deployment.
- Not a Strategy Editor V2 or Strategy Generator.
- Not Live Trading.

This is a paper-first product. Strategy Library is the catalog of certified membership.
