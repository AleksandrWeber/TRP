# PC-10 Market State Product — User Value

**Package:** PC-10  
**Date:** 2026-08-15

Operators can inspect Market State as a product. They can see Market State Home, current state, lifecycle, transitions, version history, version details, metadata, current Qualification reference, current Profile reference, and refresh the existing snapshot.

This is Orchestrator selection context, not Risk and not execution. It does not classify markets, select strategies, force trades, or start sessions.
