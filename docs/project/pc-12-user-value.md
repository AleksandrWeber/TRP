# PC-12 Exchange Scope Product — User Value

**Package:** PC-12  
**Date:** 2026-08-15

Operators can manage Exchange Scope as a product. They can see workspace Clusters, the known exchange list, the current active Cluster, and existing versions, bindings, policy inputs, lifecycle, history, and metadata. They can create, rename, activate, suspend, and archive using the existing owner.

This is isolation configuration for Deployment, Orchestrator, and Command Center. It is not a live exchange terminal and not a second Risk or Runtime engine.
