# PC-07 Notification Channels Product — User Value

**Package:** PC-07  
**Date:** 2026-08-15

Operators can now work with Notification Channels as one customer product.

Before this package, Notification Delivery already routed and Telegram could be connected, but Telegram was a standalone surface and other catalog channels were invisible.

After this package, an operator in a workspace can:

- Open Notification Channels and see every catalog channel
- Enable Telegram as the preferred offered channel
- Configure Telegram (connect, verify, test, disconnect) without typing a chat id
- See what Email, Slack, Discord, Teams, and Push will require when offered — without fake live forms
- Configure routing for the 13 existing notification types
- Set global quiet hours, timezone, and daily preference-clock time
- Inspect per-channel delivery history and diagnostics

They still cannot activate live Email/Slack/Discord/Teams/Push, save SMTP or webhooks, run hourly/weekly digests, set per-channel quiet hours, invent new notification types, call Telegram Bot API, or use a channel as a trading control plane.
